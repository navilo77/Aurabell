# M1.3 — Users Endpoints API Specification

Base path: `/api/v1/users`

All endpoints require authentication via `Authorization: Bearer <access_token>`.

---

## GET /users/me

Get current user's profile.

### Response (200)

```json
{
  "id": "uuid",
  "email": "user@example.com",
  "full_name": "John Doe",
  "phone": "+8801712345678",
  "avatar_url": "https://...",
  "status": "active",
  "created_at": "2026-11-14T10:00:00Z",
  "updated_at": "2026-11-14T10:00:00Z"
}
```

### Errors

| Status | Code | Message |
|--------|------|---------|
| 401 | *auth errors* | See auth endpoints |
| 404 | PROFILE_NOT_FOUND | Profile not found |

---

## PATCH /users/me

Update current user's profile.

### Request

```json
{
  "full_name": "Jane Doe",
  "phone": "+8801812345678",
  "avatar_url": "https://..."
}
```

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| full_name | string | No | Max 150 chars |
| phone | string | No | Max 20 chars |
| avatar_url | string | No | Valid URL |

### Response (200)

Same as GET /users/me with updated values.

### Errors

| Status | Code | Message |
|--------|------|---------|
| 401 | *auth errors* | See auth endpoints |

---

## POST /users/me/addresses

Create a new address for current user.

### Request

```json
{
  "recipient_name": "John Doe",
  "phone": "+8801712345678",
  "division": "Dhaka",
  "district": "Dhaka",
  "upazila": "Gulshan",
  "area": "Gulshan-1",
  "address_line": "House 12, Road 45",
  "postal_code": "1212",
  "is_default": true
}
```

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| recipient_name | string | Yes | 1-150 chars |
| phone | string | Yes | 1-20 chars |
| division | string | Yes | 1-100 chars |
| district | string | Yes | 1-100 chars |
| upazila | string | No | Max 100 chars |
| area | string | No | Max 150 chars |
| address_line | string | Yes | Required |
| postal_code | string | No | Max 20 chars |
| is_default | boolean | No | Default: false |

**Note**: If `is_default=true`, other addresses for this user are set to `is_default=false`.

### Response (201)

Same as address object in GET response.

### Errors

| Status | Code | Message |
|--------|------|---------|
| 401 | *auth errors* | See auth endpoints |
| 422 | VALIDATION_ERROR | Invalid input |

## PATCH /users/me/addresses/{address_id}

Update an address.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| address_id | string (UUID) | Address ID |

### Request

```json
{
  "phone": "+8801812345678",
  "is_default": true

```

| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| recipient_name | string | No | 1-150 chars |
| phone | string | No | 1-20 chars |
| division | string | No | 1-100 chars |
| district | string | No | 1-100 chars |
| upazila | string | No | Max 100 chars |
| area | string | No | Max 150 chars |
| address_line | string | No | - |
| postal_code | string | No | Max 20 chars |
| is_default | boolean | No | - |

**Note**: If `is_default=true`, other addresses for this user are set to `is_default=false`.

### Response (200)

### Errors

| Status | Code | Message |
|--------|------|---------|
| 401 | *auth errors* | See auth endpoints |
| 404 | ADDRESS_NOT_FOUND | Address not found or doesn't belong to user |

---

## DELETE /users/me/addresses/{address_id}

Delete an address.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| address_id | string (UUID) | Address ID |

### Response (204)

### Errors

| Status | Code | Message |
|--------|------|---------|
| 401 | *auth errors* | See auth endpoints |
| 404 | ADDRESS_NOT_FOUND | Address not found or doesn't belong to user |

---

## Authorization Notes

- All endpoints require valid JWT with `aud="authenticated"` and correct `iss`
- User must have profile in `profiles` table (linked via `auth.uid()`)
- Addresses are scoped to `user_id` — users cannot access other users' addresses
- RLS policies enforce this at database level as defense-in-depth

## Example Usage

```bash
# Get profile
curl -X GET http://localhost:8000/api/v1/users/me \
  -H "Authorization: Bearer <access_token>"

# Update profile
curl -X PATCH http://localhost:8000/api/v1/users/me \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"full_name": "Jane Doe"}'

# List addresses
curl -X GET http://localhost:8000/api/v1/users/me/addresses \
  -H "Authorization: Bearer <access_token>"

# Create address
curl -X POST http://localhost:8000/api/v1/users/me/addresses \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "recipient_name": "John Doe",
    "phone": "+8801712345678",
    "division": "Dhaka",
    "district": "Dhaka",
    "address_line": "House 12, Road 45"
  }'

# Update address
curl -X PATCH http://localhost:8000/api/v1/users/me/addresses/<address_id> \
  -H "Authorization: Bearer <access_token>" \
  -H "Content-Type: application/json" \
  -d '{"is_default": true}'

# Delete address
curl -X DELETE http://localhost:8000/api/v1/users/me/addresses/<address_id> \
  -H "Authorization: Bearer <access_token>"
```
