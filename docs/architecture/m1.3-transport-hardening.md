# M1.3 — Transport Hardening

## Middleware Stack

```python
# app/main.py (order matters - first added = outermost)

# 1. TrustedHost - validates Host header
app.add_middleware(TrustedHostMiddleware, allowed_hosts=[...])

# 2. CORS - cross-origin resource sharing
app.add_middleware(CORSMiddleware, ...)

# 3. Session - secure cookies
app.add_middleware(SessionMiddleware, ...)

# 4. HSTS - custom middleware for Strict-Transport-Security header
@app.middleware("http")
async def add_hsts_header(request, call_next):
    response = await call_next(request)
    response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains; preload"
    return response
```

## HSTS (HTTP Strict Transport Security)

**Header**: `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`

| Directive | Value | Purpose |
|-----------|-------|---------|
| `max-age` | 31536000 (1 year) | Browser caches HTTPS requirement |
| `includeSubDomains` | present | Applies to all subdomains |
| `preload` | present | Eligible for browser preload lists |

**Effect**: Browser refuses HTTP connections for 1 year after first HTTPS visit.

## Secure Session Cookies

```python
app.add_middleware(
    SessionMiddleware,
    secret_key=settings.SUPABASE_SERVICE_ROLE_KEY,
    session_cookie="aura_session",
    max_age=86400,        # 24 hours
    same_site="lax",      # CSRF protection
    https_only=False,     # True in production
)
```

| Attribute | Value | Security Benefit |
|-----------|-------|------------------|
| `Secure` | `https_only=True` (prod) | Only sent over HTTPS |
| `HttpOnly` | Always | Inaccessible to JavaScript |
| `SameSite` | `lax` | CSRF mitigation |
| `Max-Age` | 86400 | Auto-expiry |

## CORS Configuration

```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000", "http://127.0.0.1:3000"],
    allow_credentials=True,      # Allow cookies/auth headers
    allow_methods=["GET", "POST", "PUT", "PATCH", "DELETE", "OPTIONS"],
    allow_headers=["*"],
    expose_headers=["*"],
    max_age=86400,               # Preflight cache 24h
)
```

| Setting | Value | Rationale |
|---------|-------|-----------|
| `allow_origins` | Explicit list | No wildcard with credentials |
| `allow_credentials` | True | Required for session cookies |
| `allow_methods` | Explicit | Principle of least privilege |
| `max_age` | 86400 | Reduce preflight requests |

## TrustedHost Middleware

```python
app.add_middleware(
    TrustedHostMiddleware,
    allowed_hosts=["localhost", "127.0.0.1", "*.localhost", "testserver"],
)
```

- Validates `Host` header against allowed list
- Prevents Host header injection attacks
- Returns 400 for invalid hosts

## CSP (Content Security Policy) - Future

```python
# Recommended for production
@app.middleware("http")
async def add_csp_header(request, call_next):
    response = await call_next(request)
    response.headers["Content-Security-Policy"] = (
        "default-src 'self'; "
        "script-src 'self'; "
        "style-src 'self' 'unsafe-inline'; "
        "img-src 'self' data: https:; "
        "font-src 'self'; "
        "connect-src 'self'; "
        "frame-ancestors 'none'; "
        "base-uri 'self'; "
        "form-action 'self'"
    )
    return response
```
