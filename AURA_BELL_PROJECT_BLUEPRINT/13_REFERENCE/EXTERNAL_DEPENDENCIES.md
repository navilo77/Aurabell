# External Dependencies (বহিরাগত ডিপেন্ডেন্সি ও সার্ভিসেস)

| সার্ভিস বা লাইব্রেরি | ধরণ | ভূমিকা ও প্রয়োজনীয়তা |
|---|---|---|
| **Supabase Platform** | Cloud BaaS | PostgreSQL ডাটাবেজ হোস্টিং, অথেনটিকেশন ও স্টোরেজ বাকেট। |
| **Vercel** | Cloud Platform | Next.js ফ্রন্টএন্ড স্টোরফ্রন্ট ও এডমিন হোস্টিং। |
| **Render / Railway** | Cloud PaaS | FastAPI পাইথন ব্যাকএন্ড ও ডকার কনটেইনার হোস্টিং। |
| **bKash / SSLCommerz**| Payment Gateway | কার্ড ও মোবাইল ব্যাংকিং পেমেন্ট প্রসেসিং। |
| **Steadfast / Pathao** | Courier Logistics | সারা বাংলাদেশে পার্সেল বিতরণ ও ক্যাশ কালেকশন। |
| **Greenweb / Elitbuzz**| SMS Gateway | ওটিপি ও অর্ডার নিশ্চিতকরণ এসএমএস ডেলিভারি। |
