# Code Review Rules (কোড রিভিউ ও পুল রিকোয়েস্ট নিয়মাবলী)

1. **নো ডিরেক্ট কমিট**: মূল `main` ব্রাঞ্চে সরাসরি কোড পুশ করা সম্পূর্ণ নিষিদ্ধ।
2. **অটোমেটেড টেস্ট পাস**: পিআর মার্জ করার পূর্বে সিআই পাইপলাইনে সমস্ত টেস্ট ১০০% পাস হতে হবে।
3. **সিকিউরিটি স্ক্যান**: কোডে কোনো সিক্রেট, এপিআই কি বা এসকিউএল কনক্যাটেনেশন নেই তা যাচাই করতে হবে।
4. **ডকুমেন্টেশন সিঙ্ক**: কোডের পরিবর্তনে যদি কোনো এপিআই বা ডাটাবেজ প্রভাবিত হয়, তবে সংশ্লিষ্ট পিআর-এ ব্লুপ্রিন্ট ডকুমেন্টের আপডেট অন্তর্ভুক্ত থাকা বাধ্যতামূলক।
