# Documentation Update Rules (ডকুমেন্টেশন আপডেট নিয়মাবলী)

* **সিঙ্ক ডিসিপ্লিন**: কোড পরিবর্তনের সাথে সাথে সংশ্লিষ্ট ডকুমেন্টেশন রিয়েল-টাইমে আপডেট করতে হবে।
* **মেটাডাটা আপডেট**: প্রতিটি নথির ফ্রন্টম্যাটারে `last_updated: YYYY-MM-DD` তারিখ এবং প্রয়োজনে `version` বৃদ্ধি করতে হবে।
* **অনুমোদন ছাড়া স্ট্যাটাস পরিবর্তন নিষিদ্ধ**: কোনো ড্রাফট বা প্রপোজড ডকুমেন্ট ওনারের লিখিত সম্মতি ছাড়া `confirmed` করা যাবে না।
