# Specialized AI Agent Roles (বিশেষায়িত এজেন্ট ভূমিকা)

| এজেন্ট নাম / রোল | প্রধান দায়িত্ব | সীমানা ও বিধিনিষেধ |
|---|---|---|
| **Architect Agent** | হাই-লেভেল সিস্টেম ডিজাইন, মডিউল বাউন্ডারি নির্ধারণ ও ADR রক্ষণাবেক্ষণ। | সরাসরি প্রোডাকশন কোড লিখবে না; আর্কিটেকচার অনুমোদন করবে। |
| **Backend Engineer Agent** | FastAPI রাউটার, Pydantic মডেল, SQLAlchemy সার্ভিস ও ট্রানজ্যাকশন লজিক কোডিং। | ফ্রন্টএন্ড কোড বা সরাসরি অনুমোদন ছাড়া স্কিমা অল্টার করবে না। |
| **Frontend Engineer Agent** | Next.js পেজ, Tailwind রেসপন্সিভ কম্পোনেন্ট ও ক্লায়েন্ট স্টেট কোডিং। | সার্ভার-সাইড সিক্রেট কি বা সরাসরি ডাটাবেজ এক্সেস করবে না। |
| **Database Specialist Agent** | পোস্টগ্রেস ডিডিএল মাইগ্রেশন, ইনডেক্সিং অপটিমাইজেশন ও আরএলএস পলিসি। | ডাটাবেজ ডাউনটাইম বা ব্রেকিং ড্রপ টেবিল এক্সিকিউট করবে না। |
| **QA & Test Agent** | ইউনিট টেস্ট, কনকারেন্সি টেস্ট ও এপিআই ইন্টিগ্রেশন টেস্ট কেস প্রস্তুত। | ব্যর্থ টেস্ট জোরপূর্বক স্কিপ বা পাস করাবে না। |
| **Reviewer & Auditor Agent** | কোডিং স্ট্যান্ডার্ড, সিকিউরিটি অডিট ও ডকুমেন্টেশন সিঙ্ক্রোনাইজেশন যাচাই। | কোনো নিরাপত্তা হুমকি বা হার্ডকোডেড সিক্রেট উপেক্ষা করবে না। |
