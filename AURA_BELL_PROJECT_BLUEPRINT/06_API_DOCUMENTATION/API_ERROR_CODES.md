# Aura Bell — API Error Codes (স্ট্যান্ডার্ড এরর কোডস)

| HTTP স্ট্যাটাস | এরর কোড | বিবরণ | সম্ভাব্য কারণ ও প্রতিকার |
|---|---|---|---|
| `400` | `INVALID_INPUT` | রিকোয়েস্ট বডি ভ্যালিডেশন ব্যর্থ | Pydantic এরর অবজেক্ট চেক করুন। |
| `401` | `UNAUTHORIZED` | টোকেন অনুপস্থিত বা অবৈধ | লগইন করে বৈধ Bearer JWT প্রদান করুন। |
| `403` | `FORBIDDEN` | পর্যাপ্ত পারমিশন নেই | ইউজার রোলে নির্দিষ্ট অপারেশন অনুমোদিত নয়। |
| `404` | `NOT_FOUND` | রিসোর্স খুঁজে পাওয়া যায়নি | আইডি বা ইউআরএল চেক করুন। |
| `409` | `STOCK_UNAVAILABLE`| ইনভেন্টরি স্টক অপর্যাপ্ত | অন্য গ্রাহক স্টক কিনে ফেলেছে; কার্ট রিফ্রেশ করুন। |
| `409` | `RESERVATION_EXPIRED` | স্টক রিজার্ভেশনের মেয়াদ শেষ | ১৫ মিনিট পার হয়েছে; নতুন করে চেকআউট করুন। |
| `422` | `PRICE_MISMATCH` | ফ্রন্টএন্ড প্রাইস মিসম্যাচ | সার্ভারে পণ্যের নতুন দাম আপডেট হয়েছে। |
| `429` | `RATE_LIMITED` | অতিরিক্ত রিকোয়েস্ট পাঠানো হয়েছে | কিছু সময় অপেক্ষা করে পুনরায় চেষ্টা করুন। |
| `500` | `INTERNAL_SERVER_ERROR` | সার্ভার ত্রুটি | এরর ট্র্যাকিং লগে বিস্তারিত পরীক্ষা করুন। |
