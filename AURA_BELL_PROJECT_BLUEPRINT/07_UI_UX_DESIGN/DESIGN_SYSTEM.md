# Aura Bell — Design System (ভিজ্যুয়াল টোকেন ও কালার প্যালেট)

## ১. কালার প্যালেট (Color Tokens)

### কমন প্ল্যাটফর্ম কালার (Neutral Palette)
* **Dark Charcoal (Primary Text)**: `#0F172A`
* **Muted Gray (Secondary Text)**: `#64748B`
* **Light Gray (Borders / Dividers)**: `#E2E8F0`
* **Pure White (Background)**: `#FFFFFF`
* **Success Green**: `#10B981`
* **Error Red**: `#EF4444`

### স্টোরভিত্তিক অ্যাকসেন্ট কালার (Store Identity Tokens)
* **Best Gadget Accent**: ইলেকট্রিক ব্লু ও সায়ান (`#0284C7` / `#0EA5E9`) — প্রযুক্তি, শক্তি ও নির্ভরযোগ্যতার প্রতীক।
* **Aura Skin Care Accent**: সফট রোজ পিঙ্ক ও প্যাস্টেল পীচ (`#E11D48` / `#FDA4AF`) — সৌন্দর্য, সতেজতা ও প্রিমিয়াম ফিল।

### 3D মল ভিজ্যুয়াল টোকেন (3D Mall Visual Tokens)
* **3D মল ব্যাকগ্রাউন্ড**: হালকা গোল্ডেন কম্বিনেশন (`#F9FAFB` / `#FEF3C7`) + হালকা মরমেইড এপ্রিকট (`#FFE4B5`) + হালকা পীচ (`#FBCFE8`)
* **3D মল এলিমেন্ট ব্যাকগ্রাউন্ড**: ক্লিয়ার হোয়াইট (`#FFFFFF`) + লাইট স্লেট গ্রে (`#F1F5F9`) + হালকা পেইজ প্লে (`#F8FAFC`)
* **3D মল টেক্সচার**: হালকা শ্যাডো ব্যাকগ্রাউন্ড (`#F3F4F6` / #F3F4F6) + সেমি-হাইনামেড (`#E5E7EB`)
* **3D মল হাইলাইট**: অ্যুরা স্কিন কেয়ারের সাক্ষাৎ গ্রে (`#CBD5E1`)
* **3D মল ওভারফ্লো**: হালকা গ্রেডিয়েন্ট (`#FFFFFF` -> `#F9FAFB`)
* **3D মল বর্ডার**: মাইক্রগ্রানাইট `#E2E8F0`

### স্টোর এন্ট্রে আইকন টোকেন (Store Entrance Icon Tokens)
* **Best Gadget মল এন্ট্রি**: আকাশী রঙের প্রান্ত (Accent 1) + উজ্জ্বলের সিমিএল (소울브ল)
* **Aura Skin Care মল এন্ট্রি**: রোজ গাঢ় (`#E11D48`) + আভিনী আভায় ম্লান ( `#FDA4AF`)
